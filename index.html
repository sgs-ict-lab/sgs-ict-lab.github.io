Meet your first programming language

What exactly is Python?

🐍 Powerful ideas. Simple code.

Python is a high-level, general-purpose programming language. It's popular because its code is relatively easy to read, making it a friendly starting point for beginners.

Python was created by Guido van Rossum and first released publicly in 1991. Its name was inspired by the comedy group Monty Python, not the snake!

Today, Python is used in websites, automation, data analysis, artificial intelligence, scientific research and more.

Python Notes 📘

Clear explanations and real code examples. Start here even if you've never programmed before.

01 · Your first Python program

print() tells Python to display something on the screen.

print("Hello, SGS ICT Lab!")
# Output: Hello, SGS ICT Lab!

02 · Variables

A variable stores a value. You can give it a meaningful name and use it later.

student = "Alex"
age = 13
print(student, age)

03 · Getting input

input() asks the user to type something. It returns text.

name = input("What is your name? ")
print("Welcome, " + name)

04 · If statements

Use if to make a decision. Notice the indentation!

score = 85
if score >= 50:
    print("Passed!")
else:
    print("Keep practicing!")

05 · Loops

A loop repeats instructions. range(5) produces the numbers 0 to 4.

for number in range(5):
    print(number)

06 · Functions

A function groups reusable instructions under a name.

def greet(name):
    return "Hello, " + name

print(greet("SGS"))

➕ Add Two Numbers

Need a hint?

04 · DECISIONS

🎯 Pass or Try Again?

Use if and else to check whether a score is at least 50.

Need a hint?

Write if score >= 50: and indent the next line.

05 · LOOPS

🔁 Count with a Loop

Print the numbers 1 through 5 using range().

Need a hint?

Try for n in range(1, 6):, followed by an indented print(n).

06 · FUNCTIONS

Need a hint?
